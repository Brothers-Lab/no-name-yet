# 参与指南（Collaboration Guide）V0.1

> 本指南提供加入本项目所需的最小协作入口，是“如何参与”而非“约束规则”。

## 1. 指南目的

帮助每位贡献者快速找到协作锚点，回答三个最常见的问题：

- 我要在哪里讨论？
- 我要在哪里提交修改？
- 项目的最终状态在哪里记录？

## 2. 三条核心原则：讨论、修改、沉淀

### (A) 所有讨论 → Issue

无论是提问、想法、异议、反馈、对指南的困惑，还是会前准备，只要你不确定，就开一个 Issue。这是项目目前的唯一的正式讨论入口。

### (B) 所有修改 → Pull Request

当你需要更新北极星愿景、调整文档、补充流程、修正错误或新增规范，一律通过 PR。它是所有正式修改的唯一入口。

### (C) 唯一真源 → `/docs`

达成共识的内容必须沉淀在 `/docs`，以确保信息不散落、历史可追踪、团队共识有迹可循。

```
/docs
  /vision     # 北极星 / MVP / 战略文件（长期演化）
  /workflow   # 工作流规范（本指南所在位置）
  /meetings   # 会议记录与结论
```

## 3. 看完仍有疑问或异议？

1. 直接开 Issue，并在标题中标注「指南疑问」，如“关于参与指南第 2 部分我有问题”。
2. 我们会在 Issue 中澄清、回答，并在必要时通过 PR 更新本指南。
3. 这样可确保指南与团队同步进化，而非一次性产物。

## 4. 基本协作闭环

1. 我有想法 / 问题 → 开 Issue  
2. 讨论达成共识 → 提 PR  
3. PR 被合并 → 内容写入 `/docs`  
4. `/docs` 成为项目的最新状态

## 5. 行为准则（最关键一句）

讨论只聚焦问题，不进行人身攻击；若出现分歧，回到北极星愿景与项目目标，而非个人喜好。

## 6. 指南如何演化

本指南会随项目发展持续迭代。任何成员都可：

- 通过 Issue 讨论疑问或提出改进建议
- 通过 PR 更新指南内容

欢迎一起让协作体验不断变好。
